# Mega Engineering Suite - Module Roadmap

This document outlines the current state and future development priorities of the Mega Engineering Suite modules.

## 1. TubeSheet Module
- **Current Status**: `FUNCTIONAL / REFINING`
- **Capabilities**: Rear & Front Tube Sheets, Front-Face Views, Side-Profile Views, Tube Layout Array Generation, Pass Partition Calculations, Bolt Generation, and Template Insertion (Anchor integration).
- **Next Priorities**: Minor drafting cleanup for leader layouts and text alignments on Front Tube Sheet.

## 2. Flange Module
- **Current Status**: `PLANNED`
- **Description**: Parametric flange generation covering standard configurations (Weld Neck, Slip-on, Blind) and custom flanges based on design conditions.
- **Dependencies**: Drawing Standards, Architecture Baseline.

## 3. Nozzle Module
- **Current Status**: `PLANNED`
- **Description**: Nozzle geometry generation, orientation projections, and automatic placement on shell/head models.

## 4. Tank Module
- **Current Status**: `PLANNED`
- **Description**: High-level parametric vessel and tank component drafting (shells, heads, saddles).

## 5. Pipe Support Module
- **Current Status**: `PLANNED`
- **Description**: Support geometry generation for structural piping grids and saddle supports.

## 6. Reports Module
- **Current Status**: `PLANNED`
- **Description**: Extraction of generated parameters into Engineering Summaries, automated Bill of Materials (BOM), and design output documentation in Excel/PDF formats.
